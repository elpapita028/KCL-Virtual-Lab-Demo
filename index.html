Aim

To verify Kirchhoff’s Current Law experimentally by measuring the currents entering and leaving a node in a parallel resistive circuit, and to show that the algebraic sum of currents at the node is zero.

By the end of this module you will be able to:

  • State Kirchhoff’s Current Law.
  • Apply Ohm’s law to find branch currents.
  • Verify ΣIin = ΣIout using a virtual ammeter.
  • Calculate percentage error between theory and measurement.

How to use: read the Theory, attempt the Pretest, follow the Procedure in the Simulation, then take the Posttest.

Theory

Kirchhoff’s Current Law (the junction rule) is based on conservation of charge: charge cannot accumulate at a node, so the total current entering a node equals the total current leaving it.

ΣIin = ΣIout   or   ΣI = 0

For a source V feeding three parallel resistors R1, R2, R3, each branch current follows Ohm’s law:

I1 = V/R1, I2 = V/R2, I3 = V/R3

At the top node, the supply current IT enters and the three branch currents leave:

IT = I1 + I2 + I3

Sign convention: currents entering the node are positive and currents leaving are negative, so the algebraic sum is zero.

Procedure

  1. Open the Simulation tab.
  2. Set the source voltage V using its slider.
  3. Set R1, R2 and R3.
  4. Read the ammeters showing IT, I1, I2 and I3.
  5. Press Record reading to add a row to the observation table.
  6. Repeat for at least four different settings.
  7. Check that ΣIin equals ΣIout and note the error in each row.
